# 前端交互改造与验证（2026-09-12）

## 本轮实现

- 自动化、简历、AI、飞书分别持有草稿。切换 Tabs 或往返工作台不销毁编辑；保存仅提交所属字段。存储失败保留草稿，保存过程中新编辑仍标记未保存。关闭浏览器页面仍会丢弃未保存草稿，不是自动保存功能。
- AI 模型与 System/User 规则使用一个页面保存入口；开关不自动保存、不清空规则。连接测试仅由用户点击触发，结果在配置改变后失效。模型与规则使用不同存储键，非原子写入；部分失败明确提示。
- 飞书关闭时保存仍可达；区分“配置完整”与实际连接验证。任务运行期间先暂停再保存，避免改变正在执行的配置。
- 简历不自动填入占位模板；显式模板/导入在已有内容时先确认，并可撤销替换。Markdown 转富文本，TXT 转普通段落，原始 HTML 转义、外部图片不加载。文件名不占用工具栏。
- 顶部导航与底部保存栏固定，中间内容滚动；简历仅正文滚动。设置内容宽屏限宽。工作台宽屏列表/详情两栏，窄屏顺序排列。
- 工作台显示配置准备状态、缺项跳转、可选岗位结果、独立 AI/投递/飞书证据与终态计数。没有岗位时不能开始或重置，不用最后一个岗位的结果代表整轮完成。
- 关键词匹配改用包含/排除 SelectButton，说明分隔规则；推荐值仅改变既定运行/基础过滤字段且可撤销；地址明确支持地址或经纬度、0 表示不限。

## 与同期运行层改动的衔接

本轮开始前及执行中，工作树已有其他采集/模型/消息桥接改动。本轮未重置或提交它们。最终回读时，`bossWorkflow` 已分离为纯采集/分析/入库流程，投递需针对单岗位确认。UI 按这一实际实现显示“不自动投递”，不再展示无效的 legacy `autoDelivery` 开关；保留历史存储值，并把 REVIEW 许可放在自动化设置中。

## 组件与兼容性

- 仍使用 PrimeVue 4 + 官方 Aura，没有引入第二组件库或自定义主题 preset。frontend-design 用于信息层级和布局，不改写基础控件视觉。
- 安装 `markdown-it 15.0.2`（MIT）、`@types/markdown-it 14.2.0`（MIT），新增 `resumeImport` 导入入口。
- 补装 `@tailwindcss/vite 4.2.4`（MIT），修复原 Tailwind 指令未经编译导致布局工具类失效的问题；`bun.lock` 已同步。Bun 安装采用项目锁；npm 安装与已有 Bun 链接结构不兼容，未依赖 npm 锁文件。
- 两项必要 CSS 兼容处理：TabPanels 默认随内容长高，因此只约束高度与滚动区域；PrimeVue 内置列表 CSS 按 Quill 1 的 `ul` 匹配，但 Quill 2 输出 `li[data-list=bullet]`，真实 Chrome 曾显示为编号，现仅修复 bullet 标记及计数。未重绘 Editor 外观。
